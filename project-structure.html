🗂 Files — What to Do in Each פירוט קבצים — מה לעשות בכל קובץ
🗄
Database Layer
שכבת בסיס הנתונים
MySQL
schema.sql
Define all tables: users, passwords, todos, posts, comments. Add primary keys, foreign keys, and constraints. Plan columns carefully.
הגדרת כל הטבלאות: users, passwords, todos, posts, comments. הגדרת מפתחות ראשיים וזרים. תכנון שדות.
seed.sql
Insert a small but meaningful sample dataset — at least 3 users, several todos and posts each, and a handful of comments.
הכנסת נתוני דוגמה: 3+ משתמשים, מספר todos ו-posts לכל משתמש, ו-comments לכל פוסט.
queries.sql
Keep ad-hoc SQL queries used during development (JOINs, aggregations, debugging). Useful as reference.
שמירת שאילתות SQL שימושיות לבדיקה, ניפוי שגיאות ופיתוח.
⚙️
Server Layer
שכבת השרת
Node / Express
index.js
Entry point. Create Express app, apply middleware (CORS, JSON parser, logger), mount route files, and start listening on a port.
נקודת כניסה לשרת. יצירת אפליקציית Express, חיבור middleware, הרכבת Routes, האזנה לפורט.
db.js
Create and export a MySQL connection pool using mysql2. Read credentials from .env.
יצירת Pool חיבורים ל-MySQL באמצעות mysql2. קריאת פרטי חיבור מ-.env.
routes/*.routes.js
Define Express Router paths (GET, POST, PUT, DELETE) for each resource. Each route calls the matching controller function. Keep routes thin.
הגדרת נתיבי Express לכל משאב. כל נתיב קורא לפונקציית controller מתאימה. שמרו על נתיבים "רזים".
controllers/*.controller.js
Business logic: parse request, call the DAL, handle errors, send the response. This is the "brain" of each route.
לוגיקה עסקית: פירוש הבקשה, קריאה ל-DAL, טיפול בשגיאות, שליחת תגובה.
dal/*.dal.js
Data Access Layer: all SQL queries live here. Export async functions like getUserById, createTodo, deletePost. No business logic — only DB calls.
שכבת גישה לנתונים: כל שאילתות SQL כאן. ייצוא פונקציות async בלבד. אין לוגיקה עסקית כאן.
middleware/auth.middleware.js
Protect private routes. Check that the request includes a valid session or token before forwarding to the controller.
הגנה על נתיבים פרטיים. בדיקת token / session לפני העברה ל-controller.
middleware/logger.middleware.js
Log every incoming request (method, path, timestamp, status). Useful for debugging and for the "advanced stages" logging requirement.
רישום כל בקשה נכנסת (method, path, זמן, סטטוס). שימושי לניפוי שגיאות.
⚛️
Client Layer
שכבת הלקוח
React
main.jsx
Render the React root. Wrap with <BrowserRouter> here (or in App.jsx). Import global CSS.
רינדור שורש React. עטיפה ב-BrowserRouter. ייבוא CSS גלובלי.
App.jsx
Top-level routing. Define <Route> paths: /login, /users/:username/.... Add a guard: redirect unauthenticated users to /login.
ניתוב ראשי. הגדרת Routes: /login ו-/users/:username/.... הגנה: הפניית משתמשים לא מחוברים ל-/login.
pages/LoginPage.jsx
Controlled form with username + password fields. On submit, POST to /api/users/login. On success save user in LocalStorage and navigate to the app page.
טופס מבוקר עם username ו-password. בשליחה — POST לשרת. בהצלחה — שמירה ב-LocalStorage וניווט לאפליקציה.
pages/AppPage.jsx
Shell page after login. Renders NavBar + nested <Outlet> for sub-pages (Info, Todos, Posts).
עמוד מעטפת לאחר כניסה. מציג NavBar ו-Outlet לדפי המשנה.
pages/TodosPage.jsx
Fetch current user's todos from server. Display sorted list with checkboxes. Add forms/buttons for Create, Update, Delete. Use useEffect + useState.
הבאת todos של המשתמש הפעיל מהשרת. רשימה עם checkboxes, טפסים ליצירה, עדכון ומחיקה.
pages/PostsPage.jsx
Show all users' posts. Allow toggling comments per post. Allow create/edit/delete only for the active user's posts. Use modals or inline forms.
הצגת כל הפוסטים. הצגת/הסתרת comments לכל פוסט. עריכה/מחיקה רק לפוסטים של המשתמש הפעיל.
hooks/useAuth.js
Custom hook: read/write current user from LocalStorage. Expose user, login(), and logout(). Use across pages for consistent auth state.
Custom hook לניהול מצב המשתמש ב-LocalStorage. חושף user, login() ו-logout().
services/api.js
Centralize all fetch calls to the server here. Export named async functions: fetchTodos(userId), createPost(data), etc. Set a base URL constant.
ריכוז כל קריאות fetch לשרת. ייצוא פונקציות async מוגדרות לכל פעולה. הגדרת base URL אחת.

🛣 Development Stages (Recommended Order) סדר שלבי הפיתוח המומלץ
א

Stage A — MySQL Database

שלב א — בסיס נתונים MySQL

Write schema.sql: create users, passwords, todos, posts, comments tables with proper relations. Run seed.sql to populate test data. Verify with a MySQL client (e.g. MySQL Workbench) before touching Node.

כתבו schema.sql עם כל הטבלאות וקשרים ביניהן. הריצו seed.sql לנתוני דוגמה. בדקו ב-MySQL Workbench לפני שמתקדמים לשרת.
ב

Stage B — Node Server + Express REST API

שלב ב — שרת NodeJS ו-Express API

Set up db.js (pool), then build DAL functions, then controllers, then routes. Test every endpoint with Postman before starting the client. Implement all CRUD for todos, posts, comments.

הקימו db.js (Pool), ואז DAL, controllers ו-routes. בדקו כל endpoint ב-Postman לפני הלקוח. ממשו CRUD מלא.
ג

Stage C — React Login + App Shell

שלב ג — עמוד כניסה ומעטפת האפליקציה

Build LoginPage with a controlled form → POST to server → save to LocalStorage. Build AppPage shell with NavBar links (Info / Todos / Posts / Logout). Add route guard in App.jsx.

בנו LoginPage עם טופס → POST לשרת → שמירה ב-LocalStorage. בנו AppPage עם NavBar. הוסיפו הגנת נתיב ב-App.jsx.
ד

Stage D — Todos Page

שלב ד — עמוד Todos

Fetch and display the active user's todos sorted by ID with checkboxes. Add an input to create a new todo (POST). Add toggle for complete/incomplete (PUT). Add a delete button (DELETE).

הצגת todos של המשתמש הפעיל, מסודרים לפי ID עם checkboxes. הוספה (POST), שינוי מצב (PUT), מחיקה (DELETE).
ה

Stage E — Posts + Comments Page

שלב ה — עמוד Posts ו-Comments

Show all posts from all users. Allow toggling comments. Edit/delete only allowed for the active user's posts and comments. Add a "new post" / "new comment" form.

הצגת כל הפוסטים. הצגת/הסתרת comments. עריכה ומחיקה רק לפריטים של המשתמש הפעיל.
ו

Stage F — Advanced Features

שלב ו — פונקציונליות מתקדמת

Add query-string filters (?_limit=, ?_page=, ?field=), access tokens, server-side logging, user management, and (optionally) Albums + Photos.

הוסיפו פרמטרי URL לסינון, Access Token, רישום בשרת, ניהול משתמשים, ואם ניתן — Albums ו-Photos.
💡 Key Tips טיפים מרכזיים

Best Practices / שיטות עבודה מומלצות

  • Keep .env in .gitignore. Never commit DB passwords.

    שמרו .env מחוץ ל-Git. אל תעלו סיסמאות!
  • Use three server layers: routes → controllers → DAL. Never put SQL directly in route handlers.

    שלוש שכבות בשרת: routes → controllers → DAL. לעולם אל תכניסו SQL לתוך ה-routes ישירות.
  • Use mysql2/promise so all DB calls are async/await.

    השתמשו ב-mysql2/promise כך שכל קריאות DB הן async/await.
  • Centralize all fetch calls in services/api.js — this makes switching base URLs trivial.

    רכזו את כל קריאות fetch ב-services/api.js — מקל מאוד על שינוי base URL.
  • Test with Postman after every new endpoint. Save your requests as a collection. בדקו ב-Postman אחרי כל endpoint חדש. שמרו את הבקשות כ-Collection.
  • Commit to Git after every working stage with a clear message.

    בצעו commit ל-Git בסיום כל שלב עובד, עם הודעת commit ברורה.
  • Think about soft delete (add an is_deleted flag) rather than removing rows permanently.

    שקלו "מחיקה רכה" (שדה is_deleted) במקום מחיקת שורות לצמיתות.
  • Put the server on port 3001, client on port 5173 (Vite default), and configure CORS on the server.

    שרת על פורט 3001, לקוח על 5173 (ברירת מחדל של Vite). הגדירו CORS בשרת.
